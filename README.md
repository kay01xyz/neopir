# NEO PI-R 香港書面語私人離線版本

此版本以使用者提供的 Form S 紙本頁面為基礎，將 240 題逐題潤飾成較自然、正式的香港繁體書面語，並按答題紙上印刷的正／反向方向計算 raw score。

## 重要限制

- 僅供持有材料者在自己電腦離線核對。
- 不應上載 GitHub、公開網站、雲端硬碟公開連結或分發給第三者。
- 潤飾只處理語句；題號、facet、正反向及計分方法維持不變。
- 潤飾文字未經心理計量重新驗證，不可視為正式或獲授權的中文版。
- 已計算 30 facet raw scores 及 5 domain raw scores。
- 已加入使用者提供的 Male／Female Adult Form S profile sheet 常模。首頁只需選擇「男」或「女」；程式會在內部把每個 facet 0–32 及 domain 0–192 的完整 raw range 轉成 T-score 20–80。
- T-score 分級：非常低 20–34、低 35–44、平均 45–55、高 56–65、非常高 66–80。
- 常模性別只影響 raw→T 轉換，不影響答案及 raw score；程式不會自行推斷性別。
- 結果頁以五級顏色、五幅六角雷達圖及一幅 30 facets 橫向圖顯示結果；詳細 raw 及 T-score 資料仍由本機程式計算，不會上傳。
- 原始逐字轉錄保留於開發工作檔，介面只顯示潤飾版本。

## 開啟

直接雙擊 `index.html`。答案及所選「男／女」只儲存在該瀏覽器的 `localStorage`；按「清除答案並重新開始」可刪除答案，再於首頁重新選擇。
